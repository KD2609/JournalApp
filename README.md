# JournalApp

JournalApp is a backend application built with Spring Boot that allows users to create and manage their personal journal entries securely.

## Features

- User registration and login
- JWT-based authentication
- Create journal entries
- View journal entries
- Update journal entries
- Delete journal entries
- User management
- Role-based authorization
- MongoDB database integration
- Redis caching
- Secure REST APIs

## Tech Stack

- Java
- Spring Boot
- Spring Security
- JWT
- Spring Data MongoDB
- MongoDB
- Redis
- Maven
